# 完整填写示例：三组虚构 AP 配对

这是纯教学例子。没有真实图像、模型、训练或评价；所有数值都是人工设定，`seed` 只是演示配对键，不能据此推断真实随机性。文件顺序展示研究记录应该怎样衔接，不声称这些文件真的在某次实验前预注册。

问题：假想候选 B 相对 A 的平均差值为正，是否足以声称每个所列 seed 都改善？

1. 阅读 [协议](PROTOCOL.md) 和 [配置](config.json)：先知道比较对象、单位和教学判定。
2. 查看 [三行输入](paired_metrics.csv)：每行有候选和同 seed 参照。
3. 在仓库根目录运行：

```bash
python tools/paired_summary.py examples/synthetic_study/paired_metrics.csv
```

4. 核对：差值 +1.0、−0.5、+1.0 pp；均值 +0.5 pp；2 正 1 负。
5. 阅读 [决策](DECISIONS.md) 和 [claim 映射](CLAIM_EVIDENCE.md)：正均值不支持“所有配对均为正”，更不支持任何真实模型有效性。

真实研究还需要你自己的数据和模型实现、预算、评价器、冻结时间及运行证据。此例仅把表格到判断的流程跑通。不要把教学数值和判定规则照搬成论文结果或通用成功门槛。
