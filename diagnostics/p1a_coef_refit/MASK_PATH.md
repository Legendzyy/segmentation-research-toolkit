# Verified segmentation path

`MASK_PATH_CLOSURE = PASS` for all 36 frozen pilot images. Native pre-threshold float32 logits and independently reconstructed logits have max/mean absolute error **0**. Native/manual binary disagreement is **0** for the default input-resolution path, low-resolution path, and tested retina masks. The retina check uses the first three post-NMS candidates per image to bound memory at the original 3k–4k image resolution. The native-order vs pre-upsampled linear-design max error is **2.288818359375e-05**, below the preregistered 1e-4 tolerance. Every default candidate is tested. The network state hash is unchanged after all inference.

Source: clean [Ultralytics commit b454f423](https://github.com/ultralytics/ultralytics/tree/b454f423600f99d41730bd75a7a26b491187de36), version 8.4.155. Local source is unmodified. Full function text, file paths and line anchors are saved in `artifacts/implementation_source_trace.md`.

1. Input: BGR image -> native `LetterBox(auto=False, new_shape=(640,640))` -> RGB BCHW float32 / 255. Actual resized dimensions are rounded; left/top padding uses native `round(pad-0.1)`. GT polygons receive the identical scale and integer padding, then independent rasterization. Original-coordinate object statistics remain separately recorded.
2. `Segment` receives P3/P4/P5 features with shapes `[1,64,80,80]`, `[1,128,40,40]`, `[1,256,20,20]`.
3. `Segment.proto(x[0])` produces **P `[1,32,160,160]`** via the upstream `Proto` convolutions and transposed-convolution upsampling. Each image's frozen bank is `[32,160,160]`.
4. `Segment.cv4` processes the three scales into `[1,32,80,80]`, `[1,32,40,40]`, `[1,32,20,20]`. Flatten/concatenate gives raw coefficients **`[1,32,8400]`**. All three branch outputs and P are actually hooked, and equal the head outputs exactly.
5. This YOLO11n head has `end2end=False`: the **one-to-many branch** concatenates decoded bbox, sigmoid class probabilities and raw mask coefficients. Class sigmoid is not mask sigmoid. Fixed confidence 0.25, class-aware NMS IoU 0.7, max_det 300. Post-NMS rows are `[x1,y1,x2,y2,confidence,class,a0,...,a31]`. Kept anchor indexes are saved and coefficient equality to those anchors is asserted.
6. Native default `process_mask(P,a,bbox,(640,640),upsample=True)` computes `a @ P.float().view(32,-1)`, reshapes to `[N,160,160]`, bilinearly upsamples logits to `[N,640,640]`, thresholds strictly `>0`, converts to uint8, then crops to the predicted box. **No mask sigmoid is applied.** Threshold >0 corresponds to sigmoid>0.5 before crop; treating zeroed logits outside crop as sigmoid>=0.5 would be incorrect.
7. Default crop uses half-open continuous-box support: integer column `x>=x1 and x<x2`, row `y>=y1 and y<y2`. With upsample=True, boxes stay in input-image coordinates. The upstream predictor then scales/clips boxes to original coordinates for its Results object. Masks remain on the input grid. The pilot evaluates on that input grid, not by resizing already-binarized masks.
8. With `upsample=False`, boxes are scaled by `[160/640,160/640,160/640,160/640]`; logits are thresholded at prototype resolution and then cropped.
9. Retina `process_mask_native` first obtains original-coordinate boxes using `scale_boxes` (remove letterbox pad, divide by gain, clip); logits are multiplied at prototype resolution, `scale_masks` removes padding and bilinearly resizes to the original image, then strict threshold and original-coordinate crop. Its binary outputs also agree with reconstruction on the bounded check.
10. Native `SegmentationPredictor.construct_result` can remove candidates whose entire mask is empty. This diagnostic fixes matching on bbox candidates before mask quality is observed; empty-mask candidates would be kept and explicitly flagged. Observed empty count is available per image in the closure manifest.

Training differs: the head returns a dictionary with raw coefficient/prototype tensors. The upstream segmentation loss uses assigned positives, GT boxes and GT masks; if needed it bilinearly interpolates prototypes to the GT mask grid, combines coefficients via einsum, applies BCEWithLogits elementwise, then crops the **loss** by GT box and normalizes by box area. It does not perform inference's threshold/crop sequence. Overlap-mask training uses instance IDs. The present diagnostic neither invokes this training loss nor trains anything: BCE is a standalone convex optimization over 32 free coefficient values only, on the exact fixed inference spatial transform.

GT-aligned oracle support is a tight raster box `[min_x,min_y,max_x+1,max_y+1)`, so every target pixel is inside it. This is privileged support, not a deployable score. Original and refitted coefficients share the same support in each comparison. A separate predicted-box fit and the crop-only ceiling distinguish localization from representation. The pre-upsampled design is used only for fast linear optimization; all reported IoUs are rendered in the native float32 operation order.

Checkpoint compatibility is strict: current upstream YOLO11n-seg with nc=2 was freshly instantiated; YAML backbone/head match, all state_dict keys and shapes match, and strict loading succeeds. Checkpoint SHA256: `eb803e39be7935144816e7eb593e6bc28dec1b9e7499f9b00bbce61a989836c3`. The historical checkpoint reports Ultralytics 8.4.14. Clean inference compatibility does **not** establish a clean historical training recipe, nor does it reproduce historical evaluator scores.
