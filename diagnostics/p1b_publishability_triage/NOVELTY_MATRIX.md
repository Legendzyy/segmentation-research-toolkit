## Five closest methods: method-level audit

**YOLACT — Sections 3.1–3.4.** A P3-derived prototype bank is upsampled; a parallel head predicts tanh coefficients. Matrix multiplication and sigmoid assemble masks. Training crops with GT boxes and area-normalizes BCE; inference crops with predicted boxes. Crucially, Section 3.4 already discusses difficult coefficient prediction, leakage, and diminishing returns from more prototypes. This blocks claiming that coefficient difficulty or compact image-specific bases are new. P1B may instead test a quantitatively stable utilization gap and its held-out recoverability under a frozen native decoder. [Method source](https://arxiv.org/html/1904.02689).

**BlendMask — Sections 3.1–3.3, equations 1–4.** Detector towers emit K×M×M attentions. The blender RoIAligns shared bases, interpolates attentions, normalizes over K with softmax, then sums their spatial products. GT proposals train the blender; predicted proposals serve inference. Its spatial weights increase per-instance spatial expressivity. It directly blocks a broad claim of combining instance context with local bases. P1B's possible distinction is keeping one K-vector and the entire original span fixed; that distinction needs empirical value, not merely fewer dimensions. [Method source](https://arxiv.org/html/2001.00309).

**SipMask — Sections 3.1–3.3, Figure 3.** A box is divided into subregions, typically 2×2, each receiving its own 32-vector. Box-informed feature alignment feeds spatial coefficient prediction; shared bases aggregate FPN context. Submasks are assembled regionally, and a mask-alignment weighting loss couples quality to detections. This already targets spatial information lost by one coefficient vector and adjacent-object separation. P1B must not rediscover that motivation as novelty. A single residual vector with frozen bases is structurally narrower, without SipMask's piecewise coefficients. [Method source](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123590001.pdf).

**K-Net — Section 3.2, equations 2–5.** Predicted masks weight dense features to assemble group descriptors. Elementwise compatibility produces gates combining group features and prior kernels. Kernel interaction uses attention and a feed-forward network; the updated kernels generate new masks, repeatedly. This is explicit context-to-kernel feedback, so “first kernel reads mask features” is unavailable. P1B's candidate boundary is one noniterative residual correction of an existing frozen detector, without interactions, new basis, or spatial coefficient fields. Whether this boundary matters scientifically remains an experimental question. [Method source](https://papers.nips.cc/paper/2021/file/55a7cf9c71f1c9c495413f934dd1a158-Paper.pdf).

**SparseInst — Sections 3.1 and 3.4.** Sigmoid instance activation maps are normalized and used to pool image features. Linear layers predict class, objectness and mask kernels from those descriptors; kernels multiply a shared mask feature map. Group-IAM aggregates multiple regions. Bipartite assignment permits sparse NMS-free output. This blocks claiming that efficient pooled context predicting mask weights is new, even without iterative updates. P1B's narrow distinction is controlled correction of an existing coefficient predictor while freezing its detector and basis. [Method source](https://arxiv.org/html/2203.12827).

## Claim boundary before results

### Additional 2026 method and implementation check

**D-FINE-seg, Sections 3.1–3.5:** fused multi-scale features form a stride-4 mask map; a three-layer query MLP produces mask embeddings. Their scaled dot product gives mask logits. Cropped BCE/Dice and auxiliary/denoising supervision train the new head. This already covers a lightweight embedding-to-mask decoder; it is not a frozen coefficient residual experiment. [Full method](https://arxiv.org/pdf/2602.23043).

The official decoder at commit `b94d6b79ed8a531d1f213c3b2dff1a874c71a90c` confirms default mask dimension 256, bilinear-plus-convolution upsampling, and `1/sqrt(C)` logit scaling. The paper overview mentions transposed convolution, while its detailed Section 3.1 and this code use bilinear upsampling. The inspected mask path reads decoder states and combines them with a separate mask-feature map; it does not implement P1B's existing-coefficient residual. Current optional nano low-level input is version-specific, not assumed to describe the paper version retrieved here. [Pinned code, mask assembly](https://github.com/ArgoHA/D-FINE-seg/blob/b94d6b79ed8a531d1f213c3b2dff1a874c71a90c/dfine_seg/model/arch/dfine_decoder.py#L1058). The source file and hashes are retained under `artifacts/literature/source_audits/dfine_seg/`.

### Additional method-level comparators if high-resolution information dominates

**PointRend, Sections 3.1–3.2:** inference repeatedly upsamples a coarse mask, selects uncertain points, and predicts them with an MLP using interpolated fine image features plus coarse mask features. Training uses uncertainty-biased random point sampling. Its output gains new pointwise spatial freedom. A P1/P3 advantage therefore cannot establish that fine local features or lightweight MLP refinement are new; only a verified fixed-span efficiency tradeoff could differ. [Method details](https://arxiv.org/html/1912.08193).

**RefineMask, Sections 3.1–3.3:** a P2 semantic branch supplies high-resolution semantic features and a foreground mask. Each refinement stage combines these with the preceding instance features/mask, applies semantic fusion and upsamples toward a 112×112 mask. Boundary-aware refinement focuses correction. This blocks a general multi-source fine-detail fusion claim. A coefficient-only probe does not perform its spatial mask reconstruction, but also cannot assume equal representation power. [Method details](https://arxiv.org/html/2104.08569).

**Mask Transfiner, Sections 3.1–3.3:** down/up-sampling defines incoherent regions, a detector predicts them, and a quadtree selects multi-scale feature points. Fine features, coarse masks, local context and position feed a transformer that corrects sparse mask labels. The paper already includes a fixed-detector oracle study replacing selected errors with GT. Thus “oracle diagnosis motivates efficient refinement” is not itself novel. P1B differs only if correction stays within the existing linear span and source-specific learnability is demonstrated. [Method details](https://arxiv.org/html/2111.13673).

Do not claim first prototype decoder, first feature-aware kernel, first mask coefficient refinement, first high-resolution local refinement, first mask representation diagnosis, or first cross-generation orchard benchmark. At most, evidence may support a particular *stable native utilization diagnosis plus capacity-controlled, source-specific, held-out correction* in the tested frozen models. Lack of a retrieved identical module does not establish novelty. PointRend, RefineMask and Mask Transfiner become central comparators if H dominates; CondInst, K-Net, SparseInst, BlendMask and SipMask remain mandatory if P dominates. An AP-negative or shuffle-insensitive result cannot support a prototype-aware paper claim.
