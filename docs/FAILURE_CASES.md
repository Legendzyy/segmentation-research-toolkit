# 从失败案例练习研究判断

这些案例取自 [历史阶段摘要](RESEARCH_LESSONS.md)。原实验的模型、预算和数据范围有限；没有独立复跑。以下“起初的理由”是依据记录整理的研究动机，“下一步练习”是教学问题，不是已执行结果或新实验授权。

## 案例一：优化器收敛了，为什么诊断仍不能通过？

**尝试为什么合理。** 固定表示、只重新拟合系数，可以帮助判断预测系数是否充分利用了现有表示。

**失败在哪里。** P1A 的优化与 native 有限精度解码没有完全闭合。小梯度不足以排除运算次序、dtype 和抵消导致的输出差异。把理想设计矩阵上的质量直接解释成可实现质量，会过早得到模型机制结论。

**后来怎样更新判断。** P1B 建立了缩放与正则约束下的新数值契约，同时重放 native 输出；P1A 原裁决保留为 E，没有被新阶段的通过追溯改写。

**练习。** 如果一个拟合问题的 loss 已稳定，而二值输出仍不同，先区分优化、浮点实现和阈值附近像素，而不是立刻更换模型结构。列出你会保存的最少五项诊断量，并解释每项排除什么问题。

## 案例二：oracle 有明显空间，为何学出来的方法仍不成立？

**尝试为什么合理。** P1B 在所测模型上观察到稳定的系数利用差距，因此训练小探针去缩小该差距有明确动机。

**反证是什么。** held-out 的 matched-IoU 有小幅收益，但特定描述子的独立价值与完整 AP/子群联合门槛没有通过。P1C/P1D 的后续分解和同预算控制也没有支持当前方法主线。

**错误跳跃。** “GT 引导重建可以更好”→“可部署预测器能学到”→“完整输出 AP 会提高”是三段不同主张，不能一步跨完。

**练习。** 某方法的共同 GT 平均 IoU 提高，但 AP 降低。写出三个可检验的替代解释，分别指定需要保存的预测信息；不要只再增加一个 loss。

## 案例三：高分辨率设计的信号，可能是谁的贡献？

**尝试为什么合理。** P1E 的薄结构诊断信号支持进入 P1F，检验更细的表示是否有用。

**反证是什么。** 来源×网格阶乘加入固定插值与算力匹配控制后，预定扩展门槛未通过；历史解释更符合插值/一般容量影响，没有建立 learned 高分辨率网格的部署优势。

**容易漏掉的混杂。** 更早的特征来源还改变语义和感受野；更密计算网格改变算力；等 FLOPs 的宽度控制又可能改变参数量和初始化。实验有控制，不等于所有混杂消失。

**练习。** 为一个“把低分辨率特征换成高分辨率特征”的方案画出 2×2 对照表。指出哪些比较能解释来源，哪些能解释网格，哪一项残余混杂仍需承认。

## 案例四：对旧 baseline 涨点，是否足够？

**历史数值。** P1D 的 M1 对配对 M0 的三 seed 平均 AP 为 +0.5253 pp，对同总训练预算 fresh75 平均 AP 为 +0.4617 pp，但 AP75 为 −0.3101 pp。M3 对 M0 平均 AP 为 +0.5162 pp，没有超过更简单的 M1；原资格门槛未通过。这些值来自来源索引登记的 P1D 资格表，并非本次重算。

**能说什么。** 存在特定 endpoint 的工程信号；简单已有头调整值得保留作参照。不能据此声称复杂残差具有互补贡献，也不能将其与另一训练预算的阶段直接排名。

**练习。** 如果论文改为“平均 AP 的质量成本交换”，还缺什么证据？哪些旧结果可以保留，哪些新 claim 需要新比较？范围调整必须记录，不能假装原门槛已通过。

## 案例五：更相关的 teacher 目标，为何确认 seed 换号？

**尝试为什么合理。** ENG04 尝试以实例对应与质量信息改善迁移目标，并分开检测与 mask 任务，具有可以反驳的设计动机。

**反证是什么。** J0 对 D0 在两个新确认 seed 的主 AP 差为 −0.6491 / +0.5145 pp；对 N0 也换号。两个结果都必须保留，不能以其中一个正数宣称可靠收益。

**尚未识别什么。** 某些比较同时改变目标来源和有效监督量，所以不能凭失败就断言实例对应思想错误。目标来源、权重、任务冲突、覆盖与排序仍是待区分解释。

**练习。** 保持检测路径不变，设计“目标来源×权重规则”的最小比较；先定义分母、空集合和有效权重统计，再讨论训练。答案应包括一个简单参照及你不打算据此主张的内容。

## 做完练习以后

用 [claim—evidence 模板](../templates/CLAIM_EVIDENCE.md) 分别写出事实、解释、未检验假设。一个好的答案可以是“当前无法归因，需要更小的对照”，也可以提出有进取性的新设计，但必须给出它可能失败的条件。

上述错误方向是所测实现与证据范围内的问题，不是禁止今后研究相邻方法的清单。
