# 发布来源与编辑范围

历史档案从 `structural_instance_seg_2026` 研究目录逐文件导出，保留 P1A–P1F 与 ENG01–ENG04 原生路径。可执行方法移植位于 `src/research_toolkit/`，来源和工程适配见 [CODE_SOURCE_MAP.json](../evidence/CODE_SOURCE_MAP.json)。原文中的学术参考保留为历史记录；运行依赖与公开数据来源另行核对。

## 原件与整理说明分开

`diagnostics/` 与 `engineering/` 下十个阶段的 127 个文件是原始资产：95 份 Markdown、17 份 JSON、10 份 CSV、5 份 PNG。原文件、公开文件的 SHA256 和逐文件转换记录见 [NATIVE_SOURCE_MAP.json](../evidence/NATIVE_SOURCE_MAP.json)。本次整理新增的 README、阶段索引和 `docs/` 阅读说明不算原件。

对原件仅做以下编辑：

- 文本文档统一 UTF-8/LF；Markdown 开头加历史记录说明。
- 将机器目录前缀替换为 `${RESEARCH_ROOT}`、`${RUNTIME_ROOT}`、`${OTHER_PROJECT_ROOT}`、`${DATA_WORKSPACE_ROOT}`、`${HISTORICAL_WRITABLE_ROOT}` 或 `${LOCAL_DOCUMENT_ROOT}`。它们分别指原研究根目录、Python 环境所在工作区、并行的另一个项目、历史数据工作区、当时可写工作区、当地文档目录；只是路径占位符，不是可执行环境变量配置。
- 已收录文件改用相对链接；原文中跨阶段相对路径有误时，只在目标唯一时修正。未收录文件的链接改为“原资产，本次未收录”，保留原路径供理解。行内代码中的历史路径/命令仍可能指向未收录依赖。
- 图片逐字节复制；CSV 保留每个非路径字段与原精度；JSON 保留全部非路径字段的值。方法、实验定义、数值、历史判断和日期未改写。

## 这次没有发布的东西

明确排除的在研项目整体不进入发布范围。原图/标注、历史样本清单、权重、逐样本预测、缓存和环境包不发布。已结束阶段的可复用模型/损失代码已移植，MLCA 源码保留原许可与署名，其余上游实现通过固定依赖安装。报告中的历史数据集名称、汇总统计、设计与正负结果保留。运行验证使用独立下载的公开小数据，不访问历史 test、不改动原研究目录。

一些原文曾作为完整本地交付包的入口，会写“资产已交付”“可复现”或列出源码/收据。那是当时本地环境的状态。公共 runner 可在新数据上训练已移植方法，但没有原样本身份与权重，不能据此宣称重现历史数值。旧预算、运行状态、权限和动作指令属于历史背景，不构成当前执行授权。

原项目 README/报告里有早期 GO、阶段性草稿和后续 STOP，它们按时间保留。阅读时以对应阶段最终报告为结论，并通过日志了解变化。与原件不一致的解读应更正整理说明，不覆盖原始证据。

## 维护检查

运行 `python tools/verify_archive.py` 核对公开原件/代码 hash、数量、JSON/CSV 可解析性、PNG 文件头、Markdown 本地链接以及禁入文件类型。运行 `python -m unittest discover -s tests -v` 检查代码契约；受影响路径另跑真实数据 smoke。工程验证不构成方法有效性证据。

源文件 SHA256 由维护者在有原仓库的环境中核对；外部读者可核对公开文件 SHA256，但仅凭清单无法独立证明未公开源文件的内容。任何后续替换原件都应保留来源和编辑记录。
