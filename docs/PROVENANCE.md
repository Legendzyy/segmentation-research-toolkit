# 来源、改写与可复现边界

本仓库首版整理日期为 2026-10-12。原始研究工作区保留在维护者本地，公开仓库使用全新 Git 历史。

## 三类材料

1. **历史结论摘要**：来自已结束的 P1A–P1F、ENG01–ENG04 阶段说明和契约。`evidence/source_index.json` 登记原文件相对位置、SHA256 与用途。原文件未随仓库发布，哈希是将来核对的承诺，不是当前独立验证能力。
2. **历史聚合证据**：`evidence/paired_confirmation.csv` 从 ENG04 四行确认表选取明确列，不改变数值；来源哈希与列映射登记在 `evidence/paired_confirmation.provenance.json`。没有图像、标签、样本 ID 或逐实例预测。
3. **新整理材料**：通用论文工作流、目录模板与标准库工具。它们不是原训练脚本的原样移植；新模板中的空项与阈值不继承任何历史冻结协议。

`examples/synthetic_study/` 的全部数值为人工设定的教学夹具，独立于历史聚合结果；不代表任何真实模型、数据或科研运行。失败案例的事实来自上述历史文档，练习题是新编教学内容，未执行的新建议不会写成历史事实。

通用论文工作流还吸收了维护者提供的内部讨论中的研究组织原则。只保留问题定义、公平比较、claim 与证据对应等通用内容，未发布内部讨论原文、路径、模型设计、参数、结果或未发表研究计划。

## 工具验证能证明什么

本地测试检查配对算术、输入拒绝、重复 seed、不同参照分组、文本索引路径和哈希变化检测。公开四行表可独立重算差值及均值。

这些检查不验证历史训练、原始评价器、数据划分正确性或任何新方法有效性。完整历史实验的复现仍缺模型代码、配置、授权数据和权重等材料。文档中的“历史报告通过”与“本次实际运行通过”应分别理解。

## 发布策略

只发布人工选定的文本文件，没有历史 `.git`、第三方源码、设备环境或运行资产。代码与文档按仓库 MIT 许可证提供；未包含的数据、论文和其他本地资产不因本仓库许可证获得授权。

`.gitignore` 和文本 manifest 都不是秘密扫描器或数据隔离系统。再次发布前仍需审查全部新增文件，尤其是日志、CSV、配置和路径字段。
