# 已结束研究的结论与可迁移经验

以下为历史本地 development 研究的整理，依据登记在 `evidence/source_index.json` 中的原始说明及小型汇总表。这里没有重新执行训练或完整评价，未公开原始数据、完整预测和权重，因此不能将文档摘要当成独立复验。

## 历史阶段摘要

| 阶段 | 历史结论 | 有价值的资产 | 不支持的外推 |
|---|---|---|---|
| P1A：固定表示的系数拟合 | E：native 数值精度门槛未闭合 | 优化、表示与实际推理解码三层检查 | 不能据此认定表示失效，也不能将程序完成当科学通过 |
| P1B：稳定 oracle 与可学习探针 | 稳定系数差距跨所测模型出现；方法发表主线 STOP | 正则数值契约、held-out 探针、复杂与简单控制 | oracle 余量与少量 matched-IoU 收益不等于完整 AP 方法成立 |
| P1C：目标、容量与解码对齐 | F：混合机制，PIVOT | 梯度与支持域契约、同身份比较 | 未支持独立的 decode-alignment 方法主张 |
| P1D：等预算资格验证 | STOP，当前系数方法线结束 | 多 seed、fresh 同预算基线及联合端点门槛 | 某一平均指标上涨不代表全面通过 |
| P1E：结构瓶颈诊断 | 薄结构诊断信号允许进入下一分支 | 候选/支持/全局表示/局部自由度分解 | GO 是进一步检验许可，不是可部署方法成功 |
| P1F：来源与网格归因 | 扩展门槛失败，通用容量效应解释更相容，STOP | 来源×网格阶乘、固定插值与计算匹配控制 | 未建立 learned 高分辨率网格的部署优势；不是所有此类设计都无效 |
| ENG01：细节与辅助边界监督 | K2 / STOP | 训练期辅助模块与部署 parity、多 seed 重复 | 单 seed 的小幅改善不能代表稳健收益 |
| ENG02：尺度/容量与简单蒸馏 | K2 / STOP；容量参照有信号，所测 KD 未达门槛 | 简单尺度与容量 headroom、强 teacher 参照 | 更大模型有用不等于该知识可被既定蒸馏方法转移 |
| ENG03：实例质量迁移 | 有限开发后未支持当前方法 | 任务分工、候选对应、强控制与完整 AP 对照 | 不将局部或单 seed 改善写成稳定完整收益 |
| ENG04：锁定新 seed 确认 | J0 完整 AP 效应换号，停止当前设计 | 同阶段 N0/D0/J0 配对、开发与确认分离 | 不证明总体效应严格为零，也不支持可靠正收益 |

这些结论有具体模型、数据和配方范围。STOP 是对阶段预定目标的裁决，不意味着记录没有价值，也不构成对相邻研究方向的普遍否定。

## 一个完整保留正负 seed 的例子

`evidence/paired_confirmation.csv` 包含历史 ENG04 两个锁定新 seed 的 J0、D0、N0 聚合 mask AP。J0 为该阶段组合设计，D0 为更简单的输出迁移参照，N0 为原生参照；这里只为演示正确配对汇总。

历史范围：同阶段、60 epoch、预定最后 checkpoint、同一 Blueberry development 视图（254 图、1803 GT）、输入网格 640、mask AP@[.50:.95]、maxDet 300。该视图不是社区官方排行榜或 final test。配方信息是对原始表的转述，当前公开包无法重建训练。

| 确认 seed | J0 − D0（百分点） | J0 − N0（百分点） |
|---|---:|---:|
| 31415 | −0.6491 | −0.5327 |
| 27182 | +0.5145 | +0.4379 |
| 两确认 seed 均值 | −0.0673 | −0.0474 |

两个配对方向均换号。旧开发 seed 不合并进上述均值。这个例子支持“当前确认不支持可靠正收益”，不能推出总体效应精确为零，也不能选择一粒正 seed 作为最终结论。

在仓库根目录运行 `python tools/paired_summary.py evidence/paired_confirmation.csv` 可以从公开表重算上述结果。这是算术核对，不是重新评价模型，更不是独立实现的 AP 验证。

## 值得保留的研究判断

1. **先修数值解释，再解释模型机制。** 优化收敛与 native 有限精度一致性是不同证据。
2. **headroom 是出发点。** 特权 oracle 有余量，不保证训练能够找到可部署预测器。
3. **简单强控制会改变结论。** 分辨率、容量、插值、训练长度及监督强度都有可能解释“新模块”的收益。
4. **局部质量与完整 AP 必须对照。** 候选覆盖、匹配身份和 score 队列变化不能被共同 GT 平均数替代。
5. **多 seed 的价值包括反证。** 换号应驱动更新判断，而不是删除不利 seed 或不断救结果。
6. **机制归因比命名更困难。** 两个变量一起变化时，即使总指标上涨，也未识别各自贡献。
7. **研究路线可以有进取性。** 有依据的组合、适配和新问题仍值得检验；历史失败限定具体方案，不关闭所有相邻创新空间。
