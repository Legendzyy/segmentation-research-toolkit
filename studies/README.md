# 独立课题

每个课题在 `studies/<id>/` 中保留自己的需求、决策、阶段和接续状态。创建入口与接续约定见[新课题工作区](../docs/NEW_STUDY.md)。本目录不附带虚构研究结果。

沿用原生阶段结构：`engineering/<stage>/`、`diagnostics/<stage>/`，阶段内保留协议、方法、配置、analysis、results、paper、执行日志、运行登记和 `RESUME.md`。课题之间不共享当前状态，根目录历史阶段保持冻结。

研究文档和小型证据可以在审查后纳入当前课题版本控制；新建目录不表示授权公开。数据、权重、预测、缓存和长日志统一放仓库根目录 `work/<study>/`，继续由 Git 忽略。
